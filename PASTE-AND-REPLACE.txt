RUSH TRACK — HOME V3 UPDATE
===========================

THIS IS AN UPDATE PACKAGE FOR YOUR EXISTING rush-track-corporate PROJECT.
You do NOT need to open a new project folder in VS Code.

HOW TO APPLY
------------
1. Extract this ZIP.
2. Inside it you will see: app, data, public.
3. Copy those 3 folders.
4. Paste them directly inside your EXISTING:
   rush-track-corporate
5. Windows will ask about files with the same names.
   Choose: Replace the files in the destination.
6. Do NOT delete node_modules and do NOT run npm install again.
7. If npm run dev is already running, refresh the browser.
   Otherwise run:
      npm run dev
8. Open:
      http://localhost:3000
